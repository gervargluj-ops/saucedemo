Saucedemo Automation
Descripción
Suite de pruebas automatizadas para Saucedemo usando Playwright, Cucumber y Page Object Model.

Tecnologías
Node.js
Playwright
Cucumber
JavaScript
Patrón de Diseño
Page Object Model (POM)

Instalación
npm install

Instalar navegadores:

npx playwright install

Ejecución
npm test

Escenarios Automatizados
Login
Login exitoso
Usuario bloqueado
Carrito
Agregar producto
Visualizar producto en carrito
Checkout
Compra exitosa

Estructura
features/ pages/ step-definitions/ hooks/

Resultado
5 escenarios automatizados 25 pasos ejecutados 5 escenarios exitosos
